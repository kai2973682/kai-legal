개인정보처리방침

시행일: 2026-11-23

1. 수집하는 정보

kai-autopost는 운영자 본인의 계정에 영상을 게시하기 위해 각 플랫폼(Google/YouTube, Meta/Instagram, TikTok)이 발급하는 접근 토큰과 계정 식별자(채널 ID, 사용자 ID)만 사용합니다. 그 밖의 개인정보는 수집하지 않습니다.

2. 이용 목적

운영자 본인이 소유한 계정에 영상과 캡션을 업로드하는 데에만 사용합니다. 광고, 판매, 분석 목적의 제3자 제공은 하지 않습니다.

3. 보관과 보호

토큰은 운영자의 컴퓨터 안에만 저장되며 외부 서버로 전송하거나 공유하지 않습니다.

4. 삭제

토큰은 운영자 컴퓨터에서 해당 파일을 지우면 즉시 삭제됩니다. 연결 해제는 각 플랫폼의 계정 설정에서 언제든 할 수 있습니다(Google: myaccount.google.com/permissions, Instagram: 설정 → 웹사이트 권한 → 앱 및 웹사이트).

5. Google API 사용

kai-autopost의 Google API 사용과 다른 앱으로의 정보 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Privacy Policy

Effective: 2026-11-23

Data used. kai-autopost uses only the access tokens and account identifiers (channel ID, user ID) issued by Google/YouTube, Meta/Instagram and TikTok, solely to publish the operator's own videos to accounts the operator owns. No other personal data is collected.

Sharing. Data is not sold or shared with third parties.

Storage. Tokens are stored only on the operator's own computer and are never sent to any other server.

Deletion. Deleting the token file removes the data immediately. Access can be revoked at any time from each platform's account settings (Google: myaccount.google.com/permissions; Instagram: Settings → Website permissions → Apps and websites).

Google API. kai-autopost's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
